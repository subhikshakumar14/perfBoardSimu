Algorithm Structure

PerfRouter models the perfboard as a 2D weighted grid and finds collision-free wire paths using a modified A* search algorithm. Here's the full breakdown:

1. Grid Representation

Each hole on the perfboard is a node in a graph. Nodes carry state: empty, component, pin, or wire. The cost to enter a node depends on its state and context.

grid[row][col] = { type: 'empty' | 'comp' | 'pin' | 'wire', netId: number, // which net owns this cell compId: number, // which component occupies wire: number, // which net's wire passes through }

2. Cost Function

Every move has a cost. The cost function encodes the routing quality goals:

function moveCost(r, c, fromR, fromC, netId) { if (outOfBounds(r, c)) return Infinity; if (cell.type === 'comp') return Infinity; // blocked if (cell.type === 'pin' && cell.netId !== netId) return 50; // foreign pin let w = 1; // base cost if (cell.wire !== null && cell.wire !== netId) w += crossPenalty; // crossing (default 15) // Aesthetic: avoid edges (keep wires centered) const edgeDist = Math.min(r, c, ROWS-1-r, COLS-1-c); if (edgeDist < 2) w += edgePenalty; // default 2 // Diagonal movement costs slightly more const isDiag = (r !== fromR && c !== fromC); if (isDiag) w += diagCost; // default 0.4 return w; }

3. A* Search

A* explores the least-cost path using a heuristic (Manhattan distance) to guide search toward the target, making it much faster than Dijkstra for sparse boards.

function astar(start, end, netId) { const open = new PriorityQueue(); // min-heap by f = g + h open.push({ pos: start, g: 0, f: heuristic(start, end) }); const gScore = {}; // best cost so far to each node const parent = {}; // for path reconstruction while (!open.empty()) { const current = open.pop(); // node with lowest f if (reached(current, end)) return reconstructPath(parent, current); for (const neighbor of neighbors(current)) { const cost = moveCost(...neighbor, netId); const tentativeG = gScore[current] + cost; if (tentativeG < gScore[neighbor] ?? Infinity) { gScore[neighbor] = tentativeG; parent[neighbor] = current; // f = g (actual cost) + h (heuristic estimate) open.push({ pos: neighbor, f: tentativeG + heuristic(neighbor, end) }); } } } return null; // no path found } // Heuristic: Manhattan distance (admissible — never overestimates) function heuristic(a, b) { return Math.abs(a[0]-b[0]) + Math.abs(a[1]-b[1]); }

4. Multi-Net Routing Order

Nets are routed in order of pin-pair distance (shortest first). This is a greedy ordering — solving simpler connections first leaves more space for complex ones.

// Sort nets by Euclidean distance between first two pins nets.sort((a, b) => dist(a.pins[0], a.pins[1]) - dist(b.pins[0], b.pins[1])); // Chain routing: for nets with >2 pins, route A→B then B→C (MST approximation) for (let i = 0; i < net.pins.length - 1; i++) { const path = astar(net.pins[i], net.pins[i+1], net.id); if (path) markWireCells(path, net.id); }

5. Neighbor Expansion (8-directional)

The router considers all 8 neighbors (4 orthogonal + 4 diagonal), allowing wires to run at 45° angles. Diagonal moves cost slightly more to bias toward Manhattan paths when cost is equal.

const DIRS = [ [0,1],[1,0],[0,-1],[-1,0], // orthogonal (cost 1) [1,1],[1,-1],[-1,1],[-1,-1] // diagonal (cost 1 + diagCost) ];

6. Crossing Detection

After routing, every wire cell is inspected. A crossing is flagged when two different nets share a cell. The crossing penalty in the cost function makes the router prefer to avoid them, but allows crossings when no clean path exists.

Complexity

A* time complexity: O(E log V) per net, where V = ROWS×COLS and E = 8V (8-connected grid). For a 30×24 board with 10 nets, this is approximately 10 × (720 × log 720) ≈ 97,000 operations — essentially instant.
